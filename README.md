# TEACH:AI — From Idea to Working Tool

Live: https://gidonkup.github.io/teach-ai/

A practical, bilingual (Hebrew + English) guide that teaches educators how to work with AI tools — from defining a need, through prompting, to building a small working tool (quizzes, lesson generators, interactive HTML activities).

Single self-contained `index.html` file: no build step, no dependencies. Open it directly in a browser, or serve it as-is via GitHub Pages / any static host.

## Run locally

Just open `index.html` in a browser.
